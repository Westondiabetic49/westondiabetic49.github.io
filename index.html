⚠️ Troubleshooting & FAQ

❓ Antivirus warning appears when I run the file. What should I do?

This occurs because code-video is a new tool, and some antivirus programs flag unknown applications. Click "More info" then "Run anyway." The software is safe and open source. You can also check the project's repository for more transparency.

❓ The video generation takes longer than expected.

Video rendering, especially hand-drawn and 8-bit styles, requires computational power. If it takes more than 10 minutes, try closing other heavy applications or using a more recent computer.

❓ I don't see the output video after generation.

Look inside the "output" folder in the same directory where code-video is installed. The file name usually matches your topic. If the folder is empty, check for an error message in the application window.

❓ The application doesn't open after double-clicking.

Ensure you have extracted all files (not running inside the ZIP). Also check that you have enough disk space (at least 200MB). Try running the file as Administrator by right-clicking and selecting "Run as administrator".
